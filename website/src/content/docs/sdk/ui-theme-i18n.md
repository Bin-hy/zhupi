SDK 的 UI 全部运行在 Shadow DOM 内，宿主页面的 CSS 不会影响它，它也不会污染宿主样式。挂载后你会看到：

- 页面右下角的悬浮按钮（显示当前页批注数/未读红点）；
- 选中文字后浮出的「批注」按钮；
- 批注抽屉：列表、搜索、筛选、排序、回复与讨论串；
- 账号中心：身份绑定、登录设备、主题与语言。

## 评论面板

| 能力 | 说明 |
| --- | --- |
| 服务端搜索 | 按引用、正文、页面、作者与评论内容匹配；输入后自动刷新 |
| 排序 | 文档顺序 / 最新发布；偏好按「API + siteKey」保存在 `localStorage` |
| 筛选 | 全部 / 我的 / 已解决 / 待审 |
| 未读 | 抽屉关闭时悬浮按钮显示红点，打开后按页面记录已读时间 |
| 草稿 | 未发布的批注按页面自动保存，重新打开编辑器可恢复 |
| 回复 | 支持 `@作者`、轻量 Markdown、`⌘/Ctrl + Enter` 发布 |
| 快捷键 | `/` 聚焦搜索，`j` / `k` 切换下一条 / 上一条 |
| 深链接 | `#annot-<id>` 自动定位并高亮 |
| orphan | 正文变化导致无法定位时，提供手动重新指定入口 |

轻量 Markdown 支持：行内代码、粗体、斜体、删除线、链接与换行。渲染前会转义全部 HTML，只放行白名单语法，因此用户输入不会执行标签或脚本。

## 账号中心

登录后可以：

- 查看当前账号与已绑定身份；
- 绑定 GitHub 或站点 OIDC 身份；
- 查看登录设备（User-Agent、IP、时间）；
- 退出当前设备或退出所有设备。

本地管理员的密码修改在管理后台 `/admin/` 的「账号设置」中完成。

站点管理员与超级管理员仍通过 `/admin/` 管理后台处理审核与站点设置。

## 主题

| 值 | 行为 |
| --- | --- |
| `auto` | 跟随系统 `prefers-color-scheme` |
| `light` | 强制浅色 |
| `dark` | 强制深色 |

- 初始化选项 `theme` 会覆盖用户上次的选择；不传 `theme` 时才读取本地记忆，再回退到 `auto`。
- 偏好按「API 地址 + siteKey」隔离，不同站点可以不同。
- 站点配置的 `themeColor` 会作为强调色默认值。
- 可以通过 `cssVariables` 覆盖 `--annot-*` 变量，见 [初始化选项](/sdk/options/)。

## 国际化

内置 `zh-CN` 与 `en`：

```js
init({ siteKey: 'YOUR_SITE_KEY', locale: 'en' })
```

- 默认语言来自站点配置的 `defaultLocale`，`init` 的 `locale` 优先。
- 用户可以在账号中心切换语言。
- 日期与相对时间按所选语言格式化。

## 移动端与可访问性

- 抽屉在窄屏下占满可视宽度，悬浮按钮位置可通过 `--annotation-fab-*` 调整。
- 弹层与抽屉带焦点陷阱（focus trap），`Esc` 关闭。
- 按钮与输入框提供可见的 `focus-visible` 样式。
- 划词仅发生在 `selectRoot` 指定的正文区域，避免误选导航。

## 浏览器支持

面向现代浏览器（ES2020+），依赖 Shadow DOM 与 `ResizeObserver`。不支持 IE 与旧版 Edge。
