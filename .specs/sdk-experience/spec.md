# Annotation SDK 用户端体验完善 · Spec

> 状态：草案 v0.1（等待评审）
> 范围：可嵌入 SDK 的用户端体验 + 最小后端补充
> 代码位置：`annotation-service/sdk/`、`annotation-service/internal/`
> 关联项目：管理后台 Web、VitePress 接入打磨（后续独立 spec）

## 背景

annotation-service 已具备多站点、GitHub/站点级 OIDC 登录、批注与评论、审核与管理 API，
并产出了可嵌入 SDK（ESM + IIFE，Shadow DOM UI）。当前 SDK 的核心链路可用：

- 选中正文 → 批注 → 发布 → 刷新恢复；
- 登录、退出、基础的批注回复/解决/删除；
- 身份绑定/解绑的极简入口。

但离「产品级」仍有明显缺口：

- 账号中心不完整：没有会话列表/撤销、没有「退出所有设备」、OIDC 已绑定状态无法判断；
- 列表只取前 100 条，没有分页与筛选；
- orphan（原文已变更）只有标记，不能手动重新定位；
- 移动端、键盘可访问性、加载/空态/错误/确认框/Toast 都比较初级；
- 主题、locale、相对时间、复制链接、深链接等体验缺失。

本子项目只做 SDK 用户端体验与管理 API 的最小补充，不包含管理后台 Web UI。

## 目标

- 让 SDK 在桌面端与移动端都达到可直接交付给第三方站点使用的完成度。
- 账号、身份、会话自助管理闭环。
- 批注列表可分页、可筛选，异常内容可恢复。
- 交互状态完整：加载、空态、错误、重试、确认、成功反馈。
- 键盘可操作、样式隔离、主题可定制。
- 保持零框架依赖与现有 `init/instance` API 兼容。

## 功能需求

### F1 登录与账号入口

- 未登录时，抽屉与唯一入口都提供明确的登录动作。
- 点击登录先展示站点可用登录方式（GitHub / 各 OIDC 提供商），选择后整页跳转到对应 IdP。
- 登录回跳后恢复当前页面、当前筛选与滚动位置，并提示登录成功。
- 已登录时展示头像（无头像用首字母占位）、显示名与退出入口。
- 会话过期（401）时清理本地登录态、提示重新登录，不丢失当前页面与筛选条件。
- 全局封禁用户登录后只保留只读浏览能力，写操作给出明确提示。

### F2 账号中心

- 身份管理：
  - 列出当前账号已绑定的身份（provider 名称、handle/email、绑定时间）；
  - 提供绑定入口；已绑定的提供商显示为「已绑定」，不重复展示可绑定按钮；
  - 解绑需要二次确认；不允许解绑最后一个身份，失败时给出明确提示。
- 会话管理：
  - 列出活跃会话：当前会话标记、User-Agent、IP、最后活跃时间、过期时间；
  - 支持撤销单个会话与「退出所有设备」；
  - 撤销当前会话后界面回到未登录状态；
  - 会话列表为空或加载失败时有明确状态。
- 站点级封禁/全局封禁在账号面板中给出状态说明。

### F3 批注列表、筛选与分页

- 抽屉顶部提供筛选标签：全部、我的、已解决、待审。
  - 「我的」在未登录时隐藏或提示登录；
  - 「待审」只展示当前用户自己的待审内容（管理员审核队列不在 SDK 内）。
- 列表首屏加载 50 条；底部提供「加载更多」，使用游标分页，不重复、不遗漏。
- 批注卡片展示：作者头像/首字母、显示名、相对时间、状态徽章（待审 / 已解决 / 原文已变更）、评论数。
- 列表默认按正文位置排序，无法定位的排在最后；点击卡片滚动并闪烁对应高亮。
- 空态、加载骨架、加载失败与重试按钮必须可见且可操作。

### F4 批注与评论交互

- 选中正文后出现工具条：批注、复制引用（复制选中文字）。
- 编辑器：
  - 展示引用文本、字数限制、发布/取消；
  - 发布中禁用按钮并显示进度；
  - 成功后 Toast 提示，失败保留输入内容并显示错误；
  - 支持 Ctrl/Cmd + Enter 发布。
- 评论：
  - 登录用户可回复；
  - 作者可删除自己的评论，管理员能力由后端校验、SDK 不展示审核队列；
  - 删除使用 SDK 内部确认框，不调用浏览器原生 `confirm`。
- 批注操作：标记解决 / 重新打开 / 删除（作者或管理员）、复制批注链接。
- 待审/拒绝内容对作者显示状态徽章与说明。
- 所有写操作都有 pending 状态，避免重复提交。

### F5 orphan 手动重定位

- 锚点匹配失败的批注显示「原文已变更」。
- 提供「重新定位」动作：
  - 进入定位模式，抽屉收起并提示「请选中新的文字位置」；
  - 用户选中文字后，使用新选区生成锚点并更新该批注；
  - 更新成功后重建高亮并 Toast 提示；
  - 取消或 Esc 退出定位模式，不修改数据。
- 仅作者、站点管理员或超级管理员可以重定位；权限失败给出明确提示。
- 重定位更新失败时保留原锚点，不破坏已有数据。

### F6 移动端体验

- 长按选中文字后可触发批注入口；工具条位置避让可视区域与软键盘。
- 窄屏（< 640px）下抽屉以全宽/底部面板形式展示，不遮挡选中文字。
- FAB 不遮挡页面关键操作，并提供安全区适配。
- 所有触控目标不小于 44×44 px。

### F7 可访问性

- 工具条、编辑器、抽屉、确认框支持键盘操作：
  - Tab 顺序合理；
  - Esc 关闭最上层浮层；
  - 抽屉与确认框打开时焦点陷阱，关闭后焦点回到触发元素。
- 所有图标按钮有 `aria-label`；状态徽章有可读文本。
- 高亮 `<mark>` 可用键盘聚焦并通过 Enter 打开对应批注。
- 亮/暗主题下的文字与背景对比度满足 WCAG AA。
- 创建成功、错误、登录状态变化通过 `aria-live` 区域播报。

### F8 主题、品牌与国际化

- 站点主题色用于高亮、主按钮与强调色。
- 支持 `auto / light / dark` 三种主题；手动切换后记住当前站点偏好。
- 暴露 CSS 变量（如 `--annotation-accent`、`--annotation-bg` 等），允许宿主覆盖。
- 文案支持中英文；优先使用 `init.locale`，其次站点默认语言；时间格式随语言变化。
- 样式继续封装在 Shadow DOM 内，不污染宿主；仅高亮 mark 的样式注入宿主文档。

### F9 深链接与复制

- 「复制批注链接」生成带 `#annot-<id>` 的当前页地址。
- 打开带 `#annot-<id>` 的页面时，SDK 加载完成后自动定位并高亮该批注。
- 剪贴板不可用时应降级为可手动复制的文本提示。
- 深链接不包含 token 或任何敏感信息。

### F10 嵌入与生命周期

- 保持现有 `init(options)` 与实例 API 向后兼容；新增配置项必须可选。
- `setPage()` 支持 SPA 路由切换，切换后重新加载列表并清理旧高亮。
- `destroy()` 清理 DOM、事件监听与高亮，可重复 init。
- 同一容器重复 init 时先销毁旧实例，避免叠加 UI。
- 事件扩展：`ready`、`login`、`logout`、`created`、`updated`、`deleted`、`error`、`pagechange`。

### F11 最小后端补充

- 允许作者或站点管理员更新批注锚点（用于 orphan 重定位），并返回更新后的批注。
- 批注列表支持按「我的」与状态筛选，筛选必须作用于全量数据而非仅已加载页。
- 站点配置接口返回 OIDC 提供商的 issuer（非敏感），供 SDK 判断已绑定状态。
- 新增能力保持现有错误码风格，并补充必要的参数校验与权限校验。

## 非功能需求

- **N1 性能**：首屏列表在本地基准下 P95 < 300ms；SDK IIFE gzip 体积控制在 100KB 以内；打开抽屉不触发额外全量请求。
- **N2 可访问性**：键盘可完成登录、筛选、创建、回复、解决、删除、重定位；焦点管理正确。
- **N3 兼容性**：支持现代常青浏览器与主流移动端浏览器；不引入前端框架运行时。
- **N4 隔离性**：除高亮 mark 与 CSS 变量外，不向宿主注入全局样式或全局变量。
- **N5 国际化**：中英文文案完整，无硬编码中文泄漏到英文模式。
- **N6 可测试性**：核心纯逻辑有单测；关键用户流程有 Playwright 端到端。
- **N7 向后兼容**：现有 `AnnotationSDK.init({ siteKey })` 调用方式与事件语义不变。
- **N8 安全**：所有用户内容按纯文本渲染或转义；复制链接与深链接不携带 token；重定位走服务端权限校验。

## 不做的事

- 不做管理后台 Web UI（站点/审核/提供商管理），作为下一个子项目。
- 不在 SDK 内提供审核队列或站点管理入口。
- 不做 Markdown / 富文本评论、图片或文件附件。
- 不做实时协作、在线状态、WebSocket 推送。
- 不做邮件/Webhook/站内信通知。
- 不做弹窗登录 + postMessage（本轮保持整页跳转）。
- 不做 React/Vue 组件封装（保持框架无关）。
- 不做离线模式或本地草稿持久化。

## 验收标准

- **AC1 登录**：未登录可看到提供商列表；选择后完成整页登录并回跳；回跳后保持当前页面与筛选；退出后回到未登录。
- **AC2 账号中心**：可查看身份与会话；绑定新身份后列表更新；已绑定 provider 显示已绑定；解绑最后一个身份被拒绝并有提示；撤销会话与退出所有设备生效。
- **AC3 筛选与分页**：四个标签切换结果正确；「加载更多」跨页无重复、无遗漏；筛选作用于全量数据。
- **AC4 批注交互**：创建、回复、解决、重新打开、删除、复制链接全部可用；删除有 SDK 内确认框；写操作有 pending 与成功/失败反馈。
- **AC5 orphan 重定位**：原文变更后可进入定位模式并选中新文字；更新成功后高亮恢复；取消不修改数据；无权限时被拒绝。
- **AC6 移动端**：窄屏下抽屉为全宽/底部面板；长按可唤起工具条；触控目标不小于 44px；软键盘不遮挡编辑器。
- **AC7 可访问性**：仅用键盘可完成登录入口、筛选、创建、回复、删除与关闭浮层；焦点陷阱与 Esc 行为正确；`aria-live` 有播报。
- **AC8 主题与国际化**：亮/暗/自动切换生效并记忆；站点主题色应用到高亮与主按钮；中英文案完整，时间格式随语言变化。
- **AC9 深链接**：复制链接后在新标签打开，自动定位到对应批注；无 token 泄漏；剪贴板失败有降级提示。
- **AC10 生命周期**：SPA `setPage` 后旧高亮清除、新页面数据正确；`destroy` 后可重复 init；同容器不会叠加 UI。
- **AC11 后端补充**：锚点更新有权限校验；筛选在跨页数据上正确；site-config 返回 issuer 且不泄露 secret。
- **AC12 兼容与质量**：现有 `init({ siteKey })` 用例不破坏；SDK typecheck/单测/build 通过；Playwright 主流程通过；IIFE gzip ≤ 100KB。

## 待确认的实现假设

1. 「待审」标签只展示当前用户自己的待审内容；审核队列留给管理后台。
2. orphan 重定位采用「重新选中文字」的方式，不做按原文搜索/逐项选择。
3. 登录保持整页跳转，登录前先弹出 provider 选择面板。
4. 会话管理调用现有 `/me/sessions` 接口，不新增后端会话能力。
5. 深链接格式为当前页 URL + `#annot-<id>`，由 SDK 自行解析。
