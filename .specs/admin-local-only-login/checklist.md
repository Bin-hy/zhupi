# 管理后台仅本地账号密码登录 · Checklist

> 状态：已确认（v1.0）
> 输入：`.specs/admin-local-only-login/spec.md`、`plan.md`、`task.md`
> 每一项通过运行代码或观察行为验证。

## 后台登录与访问控制

- [ ] 打开 `/admin/login` 只看到用户名/密码表单，没有 GitHub / OIDC 按钮（AC1）
- [ ] 访问旧后台外部登录地址返回 404（AC1）
- [ ] 错误密码与不存在用户名返回同一提示（AC2）
- [ ] 连续登录失败触发限流（AC2）
- [ ] 被封禁账号登录被拒绝并提示封禁（AC2）
- [ ] 访客 OIDC/调试会话调任一管理 API 返回 403，同一令牌调站点公共 API 正常（AC3）
- [ ] 来源为 `legacy` 的旧会话调管理 API 返回 403，站点 API 正常（AC4）
- [ ] 用本地密码重新登录后旧外部会话不再可用，新会话可访问后台（AC4）
- [ ] 站点管理员本地登录后只能访问被授予站点（AC5）

## 管理员账号

- [ ] 超管新建管理员后，新账号首次登录被强制改密（AC6）
- [ ] 为已有用户开通本地密码后，其历史批注、审核记录与已绑定身份仍归属同一账号（AC7）
- [ ] 对已有本地密码的用户重复开通报错（AC7）
- [ ] 超管重置他人密码后：旧密码失效、目标全部会话失效、新密码登录要求改密（AC8）
- [ ] 撤销最后一个超管、封禁最后一个可登录超管均被拒绝；其他超管可正常撤销/封禁（AC9）
- [ ] 用户名重复（大小写不敏感）、格式非法、密码过短均返回明确校验错误（AC10）
- [ ] 强制改密状态访问管理列表返回 `password_change_required`（AC11）
- [ ] 改密成功后当前会话保留、其他会话吊销（AC11）

## 身份绑定

- [ ] 账号设置页显示已绑定身份、GitHub 可用性与按站点分组的 OIDC 提供商（AC12）
- [ ] 绑定成功后显示新身份，不新增用户与会话，且该身份无法用于后台登录（AC12）
- [ ] 绑定已被其他用户占用的身份返回冲突提示（AC13）
- [ ] 有本地密码的账号可解绑全部身份；纯访客账号不能解绑最后一个身份（AC13）
- [ ] 绑定失败回跳账号设置页并显示原因，不出现原始错误页（AC14）

## 移除外部直登与自动超管

- [ ] 设置 `SUPERADMIN_GITHUB_LOGINS` 后，命中用户通过 GitHub 访客登录不再获得超管（AC15）
- [ ] `admin promote --github-login` 不可用（AC15）
- [ ] 后台 GitHub/站点 OIDC 直登路由与登录页入口均不存在（AC1、AC15）

## 站点访客侧

- [ ] SDK 登录面板仍只展示站点 OIDC / GitHub；后台本地账号不能用于 SDK 登录（AC16）
- [ ] 访客批注、审核、封禁流程行为不变（AC16）

## 升级与 CLI

- [ ] `admin password reset --username <任意本地管理员>` 可重置并成功登录（AC17）
- [ ] `admin users open` 可为已有用户开通密码，生成密码可登录（AC17）
- [ ] 升级后未开通本地密码的旧管理员被拒绝进入后台，超管开通后恢复（AC17）
- [ ] 迁移后用户、身份、站点、批注、审核数据完整（AC18）
- [ ] 旧环境变量保留时服务正常启动（AC18）

## 集成与架构

- [ ] 全部管理 API（站点、审核、提供商、封禁、用户、管理员）都经过本地会话检查
- [ ] 登录、站点公共、账号绑定回调等公开接口不受本地会话检查影响
- [ ] 首次改密前仍可访问账号设置与身份绑定接口
- [ ] 用户名大小写不敏感唯一；重复建号不留下孤儿用户
- [ ] 站点管理员列表包含显示名与本地账号状态
- [ ] 生成的初始密码只在创建/重置响应中出现一次，之后任何接口不可读取

## 编译与测试

- [ ] `go vet ./...` 通过
- [ ] `go test ./...` 通过
- [ ] `cd admin && npm run typecheck && npm test` 通过
- [ ] `cd sdk && npm run typecheck && npm test` 通过
- [ ] `make admin` 与 `make server` 通过
- [ ] 文档检索无 `SUPERADMIN_GITHUB_LOGINS`、旧后台登录路由等遗留表述（AC20）
- [ ] 应用日志包含建号、重置、角色变更、本地登录失败，且不含密码明文或哈希（AC21）

## 端到端场景

- [ ] **全新部署**：启动 → `admin/admin` 登录 → 强制改密 → 新建管理员 → 新管理员登录并改密 → 进入后台（AC2、AC6、AC11）
- [ ] **升级切换**：旧外部会话调管理 API 失败 → 超管本地登录 → 为旧管理员开通密码 → 对方改密后恢复（AC4、AC17）
- [ ] **访客链回归**：访客登录创建批注与评论 → 站点管理员本地登录后审核通过 → 访客看到结果（AC16）
- [ ] **绑定失败回跳**：制造身份冲突 → 回跳账号页显示错误 → 已有身份未改变（AC14）
- [ ] **移除回归**：配置旧自动超管变量启动 → 服务正常 → GitHub 访客登录不获得超管（AC15、AC18）
- [ ] **真实 IdP 绑定**：在具备 OIDC 的环境完成绑定成功与解绑（无法自动化时记录为手工验证项）
