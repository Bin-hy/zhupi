## K. 端到端场景

- [ ] 场景 1：超管登录与概览
  - 注入超管 token → 打开 `/admin/` → 概览卡片与最近待审显示正确 → 刷新后仍保持登录。
- [ ] 场景 2：站点生命周期
  - 创建站点 → 列表出现 → 编辑审核模式 → 轮换 siteKey → 旧 key 请求 403 → 停用站点 → SDK 请求被拒。
- [ ] 场景 3：审核闭环
  - pre 模式站点创建批注 → 后台待审列表出现 → 通过 → 公开可见 → 再创建一条 → 拒绝 → 公开不可见。
- [ ] 场景 4：封禁
  - 站点管理员封禁用户 → 该用户本站写 403 → 其他站点可写 → 解封恢复。
- [ ] 场景 5：权限隔离
  - 站点管理员登录 → 只看到本站点 → 直接请求其他站点审核接口返回 403 → 用户管理菜单不可见。
- [ ] 场景 6：OIDC 提供商
  - 新增合法提供商（假 IdP）→ 列表与 site-config 可见 → 编辑保持 secret → 停用后登录入口消失。
- [ ] 场景 7：深链与刷新
  - 直接打开 `/admin/sites/1?tab=providers` → 页面正常加载 → 刷新不 404。
