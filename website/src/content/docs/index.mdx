## 它是什么

朱批是一个**自托管**的划线批注服务：把「选中文字 → 划线 → 批注与回复」嵌入到博客、文档站、知识库或任何 Web 页面中。它不是 SaaS，也不替你做托管；你部署一个实例，就能为多个站点提供批注能力。

| 特性 | 说明 |
| --- | --- |
| 多站点 | 一个实例托管多个站点，按 siteKey 与 Origin 白名单隔离 |
| 可嵌入 | Shadow DOM UI，不污染宿主样式；支持 `<script>` 与 ESM |
| 自托管友好 | 单 Go 二进制，内嵌 SDK 与管理后台，SQLite 单文件存储 |
| 登录 | 全局 GitHub OAuth + 每站点 OIDC + 本地超管兜底 |
| 治理 | 超管 / 站点管理员两级权限，审核队列、封禁、先审后发 |
| MIT | 代码与 SDK 均为 MIT 许可 |

:::note[名字]
「朱批」取自古人用朱笔在书页、奏折上圈点批注：红笔划过重点，批语留在页边。和同门的 **yufu（鱼符）** 一样，用一个有身份的古物指代产品本质——鱼符管身份，朱批管批注。
:::
